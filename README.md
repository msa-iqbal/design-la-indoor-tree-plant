# Indoor Tree Plant Website 🌱

This is a fully responsive website for showcasing indoor plants, built using **TailwindCSS**, **SwiperJS**, and **ScrollRevealJS**. The project includes animations, a responsive navigation menu, and interactive sections to enhance the user experience.

## Features ✨

- **Responsive Design**: Fully responsive across all devices.
- **SwiperJS Integration**: Smooth and customizable sliders for reviews and other sections.
- **ScrollRevealJS Animations**: Beautiful scroll-based animations for various elements.
- **TailwindCSS Styling**: Modern and utility-first CSS framework for styling.
- **Interactive Navigation**: Hamburger menu for mobile devices and active link highlighting.
- **Custom Animations**: Unique animations for elements like scaling, rotating, and moving.
